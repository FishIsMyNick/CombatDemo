# CombatDemo

The game is a simple demo with a movable Player Character which has a Punch Attack Combo (hold left mouse button), a Kick Attack Combo (hold right mouse button), a Dash Combo (hold left shift), and a Slam Ability (press e). All the combos can be stopped by releasing it's key binding, the Dash Ability cancels the Attack Abilities, and the Slam Ability cancels all other abilities.
The enemies are Cannon Lizards. They have an auto-roam feature and a sensing cone. When they detect the Player they will attempt to move in range for their Shooting Attack Ability (launching spit balls). If the Player comes withing their hit attack range, they will attempt to hit the player, dealing massive damage. 
All of the Player's and Enemies' abilities are implemented using the Gameplay Ability System.
The goal of the game is to kill all 7 of the Cannon Lizards on the map.
The default map should be 'Desert_A'.
